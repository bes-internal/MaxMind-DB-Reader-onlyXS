# CONTRIBUTING

Thank you for considering contributing to this distribution.

If you have a question, a bug report or a patch, use the GitHub issue tracker
or send a pull request: https://github.com/bes-internal/MaxMind-DB-Reader-onlyXS

## Building and testing

The module links against [libmaxminddb](https://github.com/maxmind/libmaxminddb)
(`libmaxminddb-dev` on Debian/Ubuntu). The tests use the `maxmind-db`
submodule:

    git submodule update --init
    perl Build.PL
    ./Build
    ./Build test

or run a single test file:

    prove -bv t/lookup.t

Development dependencies (Dist::Zilla and its plugins) are installed with
[cpm](https://metacpan.org/pod/App::cpm) into `dev/local`, see "Develop CPAN
release" in the [README](README.md):

    perl dev/dev.pl
    perl dev/exec.pl dzil test

To check the module against specific libmaxminddb versions:

    perl dev/test-libmaxminddb.pl 1.9.1 1.14.1

`Build.PL`, `META.json`, `META.yml`, `MANIFEST`, `LICENSE`, `cpanfile`,
`c/ppport.h` and `lib/MaxMind/DB/Reader/onlyXS.pm` are generated by
`dzil build`, change `dist.ini` instead of editing them by hand.

## Dependencies

The module is used from CGI scripts, so loading it must stay cheap: do not add
`use` of other modules to `onlyXS.pm` (`t/lazy-load.t` checks this). Load
what is rarely needed lazily from the XS code, like `Math::Int128` for the
`uint128` values.

The upstream project is
[MaxMind-DB-Reader-XS](https://github.com/maxmind/MaxMind-DB-Reader-XS).
